# Algorithms and Logic in Nexora

## 1. User login validation
1. Read the entered username and password.
2. Compare them with the demo account records.
3. If a match is found, open the application; otherwise, show an error.

## 2. Friend request workflow
1. Select a user to connect with.
2. Create a pending request.
3. The recipient can accept or reject the request.
4. If accepted, update the friendship relationship.

## 3. Post interactions
1. Select a post.
2. Apply the selected action (like, comment, or share).
3. Update the relevant post data.
4. Refresh the displayed content.

## 4. Community detection (label propagation demonstration)
1. Assign an initial label to each node in the graph.
2. Visit nodes and inspect the labels of their neighbours.
3. Update a node to the most common neighbour label.
4. Repeat for several rounds until labels stabilize or the demonstration stops.
5. Nodes with the same label are grouped as a community.

## 5. Analytics display
1. Collect the relevant demo counts.
2. Pass the values to chart components.
3. Display the summary using charts.
