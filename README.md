# Nexora – Social Network Simulation System

A Data Structures mini project that simulates a social networking platform using HTML, CSS, and JavaScript.

## Features
- User registration, login, and password reset
- User profiles and profile pictures
- Friend requests and friend lists
- Posts, likes, comments, and sharing
- Communities
- Notifications
- Analytics charts
- Social network graph and community detection
- Admin dashboard
- Light and dark themes

## Run the project
Open `index.html` in a modern web browser.

The project uses browser `localStorage` for demo data. Data is stored in the browser and is not shared between different users or devices.
